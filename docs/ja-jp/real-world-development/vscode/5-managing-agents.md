GitHub Copilot をエージェントモードで使うと、コードベースを調査し、変更を提案し、ファイルを編集してコマンドを実行するなど、自律的に作業します。VS Code の Copilot Chat では、エージェントがローカル環境でリアルタイムに作業する様子を確認できます。すべてのツール呼び出しとファイル編集が表示されます。差分をインラインで確認し、変更を個別に適用または取り消し、エディターを離れずに追加のプロンプトで会話を誘導して作業を改善・拡張できます。

この演習では、次のことを行います。

- アクセシビリティエージェントの作業をリアルタイムで監視します。
- 提案されたファイル編集を確認して適用します。
- セッション中にエージェントを誘導し、高コントラストに加えてライトモードの切り替えを追加します。

## シナリオ

[演習 4][previous-lesson]で使用したアクセシビリティ用カスタムエージェントは、高コントラストモードを実装しています。作業中にデザインチームから追加の依頼がありました。既定のテーマが暗すぎると感じるユーザー向けに、ライトモードの切り替えも追加してほしいとのことです。新しい会話を最初から始める代わりに、既存のセッションを誘導して作業を拡張します。

## Copilot の進行状況を監視する

Copilot Chat ビューには、エージェントが実行する各手順が表示されます。調査するファイル、実行するコマンド、提案する編集を確認できます。各ファイルの編集は、差分と **Keep** / **Undo** の操作とともにチャット内に表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、ツール呼び出しを確認します。ファイルの読み取り、編集、実行を求められたターミナルコマンドが表示されます。
3. エージェントがファイルの編集を提案すると、差分がインラインで表示されます。
    - **Keep** を選択すると変更を適用します。
    - **Undo** を選択すると変更を取り消し、エージェントに再度作業してもらいます。
4. チャット上部の **Files changed** を開くと、このセッション中にエージェントが変更したファイル全体を確認できます。

> [!NOTE]
> ターミナルコマンドの実行などに許可が必要な場合、エージェントは一時停止して **Allow** の確認を表示します。内容を確認し、許可できるコマンドだけを承認してください。

5. エージェントが高コントラストモードの実装を完了するまで待ちます。最終メッセージに変更内容がまとめられます。

## エージェントにライトモードを追加するよう依頼する

高コントラストモードが実装されたので、同じ会話を続けてライトモードの切り替えも追加します。チャットセッションを続けることで、エージェントは前の作業のコンテキスト、変更したコンポーネント、スタイルの方針、設定した local storage のパターンを維持できます。

1. Copilot Chat の入力欄に、次の追加プロンプトを送信します。

    ```plaintext
    Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
    ```

2. エージェントは前の変更を確認し、ライトモードを追加する提案を行います。
3. 新しい編集を確認します。高コントラストの変更と同様に、差分ごとに **Keep** または **Undo** を選択します。
4. エージェントが希望しない方針に進んだ場合 (たとえば、好みと異なる方法でトグル UI をリファクタリングする場合) は、チャット入力欄の横にある **Stop** ボタンで停止し、追加のメッセージで意図を明確にします。

> [!TIP]
> 進行中のセッションを誘導すると、最初からやり直すより効率的です。追加のプロンプトで調整を依頼できます。たとえば、「CSS を簡潔にして、セレクターを重複させず CSS 変数を使う」、「トグルを 3 つに増やさず、既存の設定パネルにライトモードを追加する」、「両方のトグルにキーボードショートカットを追加する」などです。

## 変更内容をまとめて確認する

変更をコミットする前に、エージェントが編集した内容全体を簡単に確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更ファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが更新されているはずです。
3. 変更したファイルをいくつか開いて差分を確認します。カスタムエージェントのアクセシビリティパターン、ARIA 属性、キーボード操作、セマンティック HTML、local storage による永続化が反映されていることを確認します。
4. 問題がなければ、Source Control パネルから変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェントモードを使って、進行中のセッションを監視して誘導しました。ファイル編集を確認しながら適用または取り消し、コンテキストを保ったまま追加プロンプトで作業を拡張しました。

このレッスンでは、次のことを学びました。

- エージェントの作業をリアルタイムで監視する方法。
- 個々のファイル編集を適用または取り消す方法。
- 追加プロンプトを使って進行中のセッションを誘導する方法。

次の[レッスン][next-lesson]では、アクセシビリティ機能をプルリクエストとして公開し、このラボ全体でローカルのカスタムエージェントが作成した変更をレビューします。
